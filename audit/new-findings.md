# New findings noticed during remediation

Issues seen while fixing audit packages that were **out of scope** for the package being worked on.
They are recorded here rather than fixed in place.

| # | Found during | Location | Finding | Status |
|---|---|---|---|---|
| N-001 | WP-3.4 | `pages/Merchants.tsx` (spend-trend months) | The six-month window is anchored to a hard-coded date (`new Date(2026, 4, 23)`), so the merchant sparklines always show Dec 2025 – May 2026 regardless of today's date. (Also noted in `findings-performance.md` → Unverified.) | **Fixed** — months come from today (local year/month, no `toISOString` shift). |
| N-002 | WP-4.1 | `index.css` | iOS-only rule `input, select, textarea { font-size: max(16px, 1em) }` was added to prevent focus-zoom now that pinch-zoom is allowed; it slightly enlarges small inputs on iOS and should be reviewed visually on a device. | **Open** — needs a visual check on a real iOS device; not changed. |
| N-003 | WP-2.13 | `utils.ts` (forecast table rows) | `{ id, date: dateStr, ...event }` set `date` twice; the spread always won. Strict mode flagged it (TS2783). The redundant key was removed in place; behaviour is unchanged, but it suggests `dateStr` and `event.date` were once meant to differ. | **Fixed** in WP-2.13 (redundant key removed). |
| N-004 | WP-4.2 | the ~31 hand-rolled overlays | Each still registers its own window-level Escape handler, so with stacked custom overlays one Escape closes all of them. Only `Modal.tsx` honours the new "topmost dialog only" rule. Moving the overlays onto `Modal` (K2, deferred primitive swap) would fix it. | **Fixed** — the overlays' window Escape handlers now require `isTopmostDialog`. |
| N-005 | WP-3.2 | `nginx.conf` | The Content-Security-Policy is shipped as `Report-Only` because it could not be verified in a real browser against the nginx image here. It should be switched to enforcing after a pass with the production bundle, and the `connect-src https:` allowance narrowed to the actual third-party hosts. | **Open** — needs a browser pass against the production bundle before enforcing. |
| N-006 | WP-2.11 | `Dockerfile` (frontend) | The nginx image still runs its master process as root (it binds port 80, and the compose/Umbrel port mappings assume it). `nginxinc/nginx-unprivileged` on 8080 would need coordinated compose changes. | **Open** — the Umbrel compose pins an image digest on port 80; needs a new image release first. |
| N-007 | WP-4.8 | `utils/privacyMask.ts` | Privacy mode now blurs any element whose own text looks like a currency amount (€, $, £, EUR/USD/GBP). Amounts in other currencies (CHF, JPY, …) and amounts split across elements are not matched; call sites should still add `.privacy-blur` where they know the value is monetary. | **Fixed** — mask covers 30 ISO codes and more symbols (unit tested). |
| N-008 | WP-1.6 | `server/src/enableBanking.ts` | The credential store holds one Enable Banking key per user, matching the single credentials form. Users who need two Enable Banking applications cannot have both. | **Open** — a product decision (multiple Enable Banking applications per user). |
| N-009 | WP-4.4 | text sizes | The floor is now 10 px (`text-2xs`); about 517 uses of `text-[10px]`/`text-2xs` labels remain below the 11–12 px that UI-008 asked for. Raising them is a visual change worth designing, not a mechanical edit. | **Fixed** — `text-2xs` is now 11px and all `text-[10px]` use it. |
